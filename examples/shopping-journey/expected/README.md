# 기대 기준

단일 노드와 A1~A7 클러스터 케이스를 평가하기 위한 문서입니다. 데이터 정확성을 먼저 통과한 뒤 성능과 가용성·복구를 비교합니다. A7은 최초 이벤트를 `occurred_at`으로 정하므로 A1~A6의 `received_at` 기준과 결과를 분리해 판정합니다.

| 구분 | 문서 | 현재 상태 |
|---|---|---|
| 데이터 결과 | [data-result.md](./data-result.md) | 샘플 기준값과 케이스별 합격 조건 확정 |
| 성능 | [performance.md](./performance.md) | 측정 항목 정의, 목표값은 부하 테스트 전에 확정 필요 |
| 가용성·복구 | [availability-recovery.md](./availability-recovery.md) | 장애 시나리오 정의, 시간·성공률 목표값 확정 필요 |

평가 순서는 다음과 같습니다.

1. 동일 입력으로 데이터 결과가 일치하는지 확인합니다.
2. 동일 데이터량·자원·동시성에서 성능을 측정합니다.
3. 장애를 주입해 서비스 지속 여부와 복구 결과를 측정합니다.

성능이 빠르거나 복구가 빨라도 데이터 결과가 틀리면 해당 케이스는 통과로 보지 않습니다.
